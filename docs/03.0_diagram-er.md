## Conceptos fundamentales

- **Entidad:** elemento del negocio que necesita representarse.
- **Atributo:** característica que describe una entidad.
- **Relación:** asociación entre dos o más entidades.
- **Cardinalidad:** cantidad de instancias que pueden relacionarse.
- **Participación:** indica si una relación es obligatoria u opcional.
- **Identificador:** atributo o conjunto de atributos que distingue una instancia.

## 3. Definición de cardinalidades

<!-- Determinar cuántas instancias de una entidad pueden asociarse con las de otra. -->

**Tipos principales:**
- **Uno a uno (1:1):** una instancia de A se relaciona con una de B y viceversa.
- **Uno a muchos (1:N):** una instancia de A puede relacionarse con varias de B, pero cada B se relaciona como máximo con una A.
- **Muchos a muchos (N:M):** varias instancias de A pueden relacionarse con varias de B.

### 3.2 Participación obligatoria u opcional

<!-- Determinar si una entidad debe participar en una relación o puede existir sin ella. -->

**Límites de participación:**
- `0..1`: cero o una instancia.
- `1..1`: exactamente una instancia.
- `0..N`: cero o muchas instancias.
- `1..N`: una o muchas instancias.
