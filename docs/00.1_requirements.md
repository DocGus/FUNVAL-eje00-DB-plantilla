# Requerimientos del Proyecto

<!--
============================================================
DOCUMENTO: 00_requirements.md
============================================================

FUNCIÓN:
Este documento registra y organiza los requerimientos del proyecto
a partir de las necesidades expresadas por el cliente.

Su propósito es comprender qué problema se desea resolver,
cómo funciona actualmente el negocio y qué necesita el cliente
del sistema que se va a desarrollar.

¿POR QUÉ ES IMPORTANTE?
Antes de diseñar una base de datos debemos comprender el contexto
del negocio. Si comenzamos a crear tablas sin entender los procesos,
podemos construir una estructura que no represente las necesidades reales.

METODOLOGÍA:
El levantamiento de requerimientos se divide en cuatro etapas:

1. Consulta inicial con el cliente.
2. Análisis de la idea e identificación de vacíos.
3. Consulta de seguimiento y validación con el cliente.
4. Consolidación de la especificación de requerimientos.

REGLA GENERAL:
No debemos presentar suposiciones como si fueran requerimientos
confirmados. Toda información pendiente de validación debe identificarse
claramente.

============================================================
ESTRUCTURA DEL DOCUMENTO
============================================================
-->
